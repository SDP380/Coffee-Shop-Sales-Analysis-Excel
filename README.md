# Coffee-Shop-Sales-Analysis-Excel
📊 Project Overview

This project analyzes coffee shop transaction data using Microsoft Excel to identify sales patterns across products, months, weekdays, and time periods.

The analysis transforms raw transaction data into meaningful KPIs, interactive visualizations, and business insights that can support sales and operational decision-making.

🎯 Business Problem

Raw transaction data can provide detailed information about individual purchases, but it does not immediately reveal which products, periods, and transaction patterns contribute most to overall sales.

This project uses Excel-based analysis to identify key sales trends and convert transaction-level data into actionable business insights.

🎯 Objectives

Analyze overall coffee shop sales performance

Identify high- and low-performing products

Analyze monthly sales trends

Identify sales patterns by time of day

Analyze sales performance across weekdays

Identify products with high transaction frequency

Build an interactive Excel dashboard

Generate data-driven business recommendations

❓ Business Questions

Which coffee products generate the highest sales?

Which months have the highest and lowest sales?

What time of day generates the highest sales?

Which days of the week perform best and worst?

Which products have the highest transaction frequency?

What is the average value of a transaction?

📊 Dashboard

The dashboard provides an interactive view of coffee shop sales performance across products, time periods, and transaction patterns.



🔍 Key Insights

Product Performance

Latte generated the highest sales among the analyzed products.

Espresso recorded the lowest sales.

Americano with Milk had the highest transaction frequency.

Monthly Performance

March recorded the highest sales.

April recorded the lowest sales.

Time-of-Day Performance

Night generated the highest sales.

Morning recorded the lowest sales.

Afternoon had the highest number of transactions.

Night had the lowest number of transactions.

Weekday Performance

Tuesday recorded the highest sales.

Sunday recorded the lowest sales.

💡 Business Recommendations

Monitor inventory availability for high-performing products.

Investigate the reasons behind lower sales during weaker months and weekdays.

Evaluate opportunities to improve morning sales performance.

Analyze purchasing patterns associated with high-transaction products.

Use historical sales patterns to support staffing, inventory, and promotional planning.
